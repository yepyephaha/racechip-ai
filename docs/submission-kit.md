## 2. 可复制作品介绍

**作品介绍**

赛芯智选 RaceChip AI 面向第一次参加电子竞赛的同学，优先解决机器人视觉赛题中“该用什么硬件、参数是否真实、能否满足赛题”的问题。用户输入赛题和预算、接口、视觉任务等要求，系统先把明确条件与待确认条件分开，再围绕候选硬件开展资料调查。元宝搜索用于查找厂商资料和社区工程经验，结论附上来源与核验状态；硬性条件不满足的候选会被排除，证据不足的参数保持未知，不把搜索相关性当成事实置信度。

P0 提供赛题文本解析、约束编辑、候选对比、来源卡片、排除原因和调查报告导出。无密钥时可使用明确标识的 mock 数据测试界面和流程；正式参赛演示须切到真实 SearchPro 模式，记录三次真实调查。它帮助新生缩小方案范围、找到需要实测的环节，不承诺任何型号一定满足赛场性能。

**场景价值**

新生选型常把开发板、芯片和整套视觉模块混为一谈，也容易把卖家宣传参数当成赛题所需性能。RaceChip 把赛题条件、型号参数、工程经验与未知项放进一份能追溯的选型记录，让同学知道为什么入选、为什么排除，以及下一步要验证什么。

**创新点**

1. 以赛题约束推动检索，把“推荐某块板”拆成多个可核查的问题。
2. 厂商参数与社区经验分层呈现，避免将经验帖直接充当器件规格。
3. 先检查硬性约束，再解释候选差异，未知信息触发待确认，而非自动通过。
4. 在页面与报告中公开搜索模式、证据状态、引用和排除理由，支持复核。

**工具使用与数据披露（按实际勾改）**

开发使用 Codex 辅助代码与文档，前端为 React/Vite，后端为 FastAPI。联网搜索使用腾讯云元宝搜索 SearchPro，当前真实实测为TC3标准签名，另兼容服务API KEY接口，密钥仅由后端环境变量读取。硬件资料以厂商公开文档为参数依据，社区内容仅作为工程经验线索。演示中的预算、赛题和 mock 搜索记录均明确标记；测试数据不是官方赛题原文，也不是实际 SearchPro 调用结果。实际完成的真实查询数量：[3/3，见本轮实录清单]，并附对应运行记录及素材。

不要填写尚未发生的用户量、准确率、节省时间比例、奖项、性能实测结果或 SearchPro 调用次数。
