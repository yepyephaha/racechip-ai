# 2026-10-25 续接验收范围

沿用用户确认的通用硬件工作台范围；原生 EDA、PCB 深度集成后置。延续 `.taste-skill/direction.json` 的 framed-sheet 方向、墨绿品牌色和既有字体。

本轮要验证的用户行为：

| 行为与可见状态 | 功能检查 | 视觉证据 |
| --- | --- | --- |
| TokenHub 实际连通、模型状态与配置入口 | 实际调用、未配置与失败不能回退固定树 | 桌面配置面板和状态 |
| 逐轮需求与需求变更 | 多轮 API、历史上下文、每次最多一个必要追问、方案更新 | 对话完成与变更后的模块 |
| 元宝器件与报价 | 真实 RequestId、商品详情链接、参考价条件 | 器件与报价页 |
| BOM、连接与兼容检查 | 编辑、明确冲突、修改后变更影响 | 工程页、验证任务 |
| 资料引用问答 | 明确标记合成输入、原句与页号 | 问答页 |
| 保存、恢复、导入、导出 | 对话恢复、工程 ZIP 内的决策和查询记录 | 下载与恢复状态 |
| 响应式与键盘 | 1440、768、390px；焦点、导航、无整页水平溢出 | 三种尺寸截图 |

额外边界：重复点击或取消请求后不得污染其他工程；刷新后模型方案和证据不得丢失或冒充新查询；报价缺失不填零、不取多 SKU 最低价。

最终检查结果与限制见 acceptance-v0.3.md；此文件只是验收清单，不代表已通过。
